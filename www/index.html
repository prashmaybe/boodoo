The best of Bootstrap · Foundation · Tailwind · Material

Build fast, responsive sites with Budu

A modular, mobile-first CSS design framework that fuses four design systems into one dependency-free, accessible, touch-friendly toolkit. Written in Sass, shipped as CSS.

Get started CDN installation 
$ npm install budu
$ sass scss/budu.scss css/budu.css
Bundled 296 kB → budu.min.css   # 12 components · 100+ utilities
◆
Mobile first

A 12-column flexbox grid from 320px to 1400px+, plus a full CSS Grid utility suite for two-dimensional layouts.

⚡
Fast & dependency-free

Vanilla JS, ~56 KB, zero runtime deps. Tweet-sized builds with grid-only and utilities-only bundles.

◒
Accessible & touch-friendly

44px targets, focus-visible, prefer-reduced-motion, ARIA wiring, and swipe support on every carousel.

✦
Source-first theming

Every color, radius, and shadow is a token. Compile your own build with Sass or Less in seconds.

Installation

Start in minutes

# Via CDN — just drop in two tags
<link href="https://budu.dihadiwala.com/dist/css/budu.min.css" rel="stylesheet">
<script src="https://budu.dihadiwala.com/dist/js/budu.js"></script>

# Or with a package manager
$ npm install budu

# Or use the Sass / Less source
@import "node_modules/budu/scss/budu";
