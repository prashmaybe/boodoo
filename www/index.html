Budu Framework v1.0 • Bootstrap + Foundation + Tailwind + Material

Build fast, responsive sites with Budu

A modular, mobile-first CSS design framework that fuses four iconic design systems into one dependency-free, accessible, touch-friendly toolkit. Written in Sass, compiled for speed.

Why budu?

Engineered for modern web applications

Combine flexbox responsive layout power with rich UI components and accessible touch interactions.

📱

Mobile first

12-column flexbox grid from 320px to 1400px+, plus a complete 2D CSS Grid utility suite.

⚡

Fast & zero-deps

Vanilla JS, ~56 KB bundle, zero runtime dependencies. Ships modular utility & grid builds.

🛡️

Accessible & touch

44px touch targets, focus-visible outlines, ARIA wiring, and swipe gesture support out of the box.

🎨

Source-first tokens

Every color, radius, and shadow is a token. Compile custom themes with Sass or Less in seconds.

Four Pillars

Four great design systems, one cohesive toolkit

budu synthesizes the best ideas from top frameworks into a single lightweight library.

🅱️

Bootstrap

Component structure, 12-col grid flex, modal overlays, data-* attributes JS API.

🏛️

Foundation

Clean structural scaffolding, rich typography scales, and subtle gray scales.

🌀

Tailwind

Functional utility classes, responsive variants, precise spacing scales.

💎

Material

Elevation shadows, motion curves, touch ripple effects, floating form labels.
