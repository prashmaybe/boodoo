Typography

Documentation and examples for budu typography, including global settings, headings, display headings, body text, and more.

Global settings

budu sets basic global display, typography, and link styles.

  • Uses a native font stack: system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif.
  • Removes the default font-size and font-weight on <h1>–<h6> margin-bottom of .625rem.
  • Sets $budu-font-weight-base to 400, $budu-line-height-base to 1.5.
  • Link color inherits the --budu-link-color token and underlines on hover.

Headings

All HTML headings are available. Use the associated classes .h1 through .h6 if you want to match the font styling without the semantic element.

Font families

Use .font-sans-serif, .font-serif, or .font-monospace to switch between budu's font stacks.

<p class="font-monospace">Monospace text</p>

budu also ships fluid type helpers .fs-fluid-1 … .fs-fluid-6 built on clamp() for scales that breathe with the viewport.
