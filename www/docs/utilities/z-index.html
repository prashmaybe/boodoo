Z-index

Control the stacking order of overlapping elements with the .z-* utilities.

Z-index utilities

Set the z-index of an element directly:

z-30
z-20
z-10
<div class="z-30">On top</div>
<div class="z-10">Beneath</div>

Available: .z-0, .z-10, .z-20, .z-30, .z-40, .z-50, and .z-auto.

Component z-indexes

Budu's components use well-defined z-index values so that dropdowns stack under navbars, modals above everything, etc. These are exposed as CSS custom properties for tweaking:

ComponentCSS variableDefault
Dropdown--budu-zindex-dropdown1000
Sticky/fixed--budu-zindex-sticky/fixed1020 / 1030
Offcanvas--budu-zindex-offcanvas1045
Modal--budu-zindex-modal1055
Popover--budu-zindex-popover1070
Tooltip--budu-zindex-tooltip1080
Toast--budu-zindex-toast1090
 
.my-modal {
  --budu-zindex-modal: 2000;  /* pushes it above the default */
}
