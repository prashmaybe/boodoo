How to Install Budu WordPress Themes

  1. Select a Layout: Choose any of the 8 specialized layout themes listed above according to your site architecture requirements.
  2. Download or Copy Theme Assets: Access the theme details page to download the pre-packaged WordPress theme ZIP or copy the style.css, functions.php, and theme.json code snippets into your theme folder.
  3. Upload to WordPress: In your WordPress admin dashboard, navigate to Appearance → Themes → Add New → Upload Theme, select the ZIP file, and click Install Now.
  4. Activate & Enjoy: Click Activate. Your WordPress site is now styled with Budu's responsive CSS, custom theme.json color palettes, and component library!
