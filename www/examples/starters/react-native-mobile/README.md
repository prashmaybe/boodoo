# Boodoo React Native Mobile Starter (Expo)

Powered by **boodoo v1.2.1** for iOS and Android.

## Features
- **Zero DOM / Pure Native**: Uses `boodoo/react-native` built on React Native `StyleSheet`.
- **Auto Theming**: Built-in Light and Dark modes with `<BoodooProvider>`.
- **No Native Linking Friction**: Runs smoothly in Expo Go and bare React Native.

## Getting Started

```bash
npm install
npx expo start
```

Press `i` for iOS Simulator, `a` for Android Emulator, or scan the QR code with the Expo Go app on your physical mobile phone.
