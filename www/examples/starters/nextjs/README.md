# boodoo Next.js Starter (App Router)

Quickly build Server-Side Rendered (SSR) and statically generated Next.js applications styled with boodoo.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the Next.js development server:
   ```bash
   npm run dev
   ```

3. Open `http://localhost:3000` in your browser.
