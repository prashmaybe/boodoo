Alerts

Provide contextual feedback messages for typical user actions with a handful of available and flexible alert messages.

Examples

Alerts are available for any length of text, as well as an optional dismiss button.

Dismissing

Add a dismiss button and the optional .alert-dismissible utility class, then use data-budu-alert + data-budu-dismiss="alert" to wire up the close button.

Holy guacamole! You should check in on some of those fields below. 
<div class="alert alert-warning alert-dismissible fade show" role="alert" data-budu-alert>
  <strong>Holy guacamole!</strong> You should check in on some of those fields below.
  <button type="button" class="btn-close" data-budu-dismiss="alert" aria-label="Close"></button>
</div>

JavaScript behavior

Alerts can also be dismissed programmatically:

// Close all alerts
document.querySelectorAll('.alert[data-budu-alert]').forEach(function (el) {
  budu.Alert.getOrCreateInstance(el).hide();
});
