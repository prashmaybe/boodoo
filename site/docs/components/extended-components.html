Floating Action Button Dock

The .fab-dock component provides a fixed multi-action button with popup action links, keyboard ESC dismissal, and click-outside tracking.

<div class="fab-dock" id="myDock">
  <button type="button" class="fab-dock-trigger" aria-label="Quick Actions">
    <span class="fab-icon-open"><span>+</span></span>
    <span class="fab-icon-close"><span>&times;</span></span>
  </button>
  <div class="fab-dock-items">
    <button type="button" class="fab-dock-item">
      <span class="fab-item-label"><span>Upload File</span></span>
      <span class="fab-item-btn"><span>&uarr;</span></span>
    </button>
  </div>
</div>

Guided Tour & Walkthrough

The boodoo.Tour class generates popover guides that walk users step-by-step through features with target element anchoring, progress dots, and keyboard navigation.

const tour = new boodoo.Tour(document.body, {
  steps: [
    { target: '#statWidget', title: 'KPI Metrics', content: 'View real-time metrics and trends.' },
    { target: '#notifications', title: 'Notifications', content: 'Stay on top of updates.' }
  ]
});
tour.start();
