Zero-Risk Adoption: From Paper to Boodoo

You don't need to rewrite your mobile codebase overnight. Boodoo provides two flexible adoption phases:

Phase 1: Skin your existing React Native Paper app with Boodoo's theme

If you already use React Native Paper, import Boodoo's ready-to-use MD3 theme preset:

import { Provider as PaperProvider } from 'react-native-paper';
import { boodooPaperLightTheme } from 'boodoo/paper';

export default function App() {
  return (
    <PaperProvider theme={boodooPaperLightTheme}>
      <YourAppNavigation />
    </PaperProvider>
  );
}

Phase 2: Transition to pure Boodoo Native components

As you build new screens or refactor existing ones, swap Paper components with lightweight Boodoo components from boodoo/react-native to eliminate bloat, simplify styling, and achieve lightning-fast render performance.

Why developers choose boodoo over React Native Paper

While React Native Paper is a capable library for Google Material Design implementations, modern mobile product teams often want an interface that feels clean, premium, and unified with their web apps rather than feeling like an Android utility. boodoo bridges that gap by offering lightweight native components, universal design tokens, and a shared visual language across Web, Desktop, and Mobile.
