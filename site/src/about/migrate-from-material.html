Why Migrate from Material Design to boodoo?

  • Eliminate 200+ KB of React Overhead: Libraries like MUI pull in Emotion or styled-components, adding huge runtime JS taxes. Boodoo runs on pure static CSS and lightweight vanilla JS.
  • Freedom from the "Pure Google" Look: Boodoo incorporates Material's depth and touch feedback while allowing sleek, custom SaaS brand aesthetics.
  • Native HTML5 Dialog & Popover: Modern dialogs and drawer sheets without complex portal lifecycles.

Material Design to boodoo Mapping

Material Feature / MUI Component boodoo Equivalent Implementation
<Paper elevation={3}> .elevation-3 or .shadow-sm Pure CSS box-shadow tokens
TouchRipple .ripple or .btn-ripple Zero-dependency CSS/JS click ripple
<TextField label="Name" variant="outlined"> .form-floating Standard CSS floating form label
<Fab color="primary"> .btn.btn-primary.btn-fab Floating action button with elevation
<Snackbar open={true}> .toast / window.boodoo.toast() Native stackable toast notifications
<SpeedDial> .speed-dial Expandable floating action menu

Code Migration Example

<!-- Before: MUI (React runtime required) -->
<Card elevation={2} sx={{ p: 3, borderRadius: 2 }}>
  <Typography variant="h5">Profile Card</Typography>
  <Button variant="contained" color="primary">Save</Button>
</Card>

<!-- After: boodoo (Clean HTML/CSS, zero dependencies) -->
<div class="card p-3 elevation-2 rounded-3">
  <h3 class="h5 fw-bold mb-2">Profile Card</h3>
  <button type="button" class="btn btn-primary btn-ripple ripple">Save</button>
</div>
