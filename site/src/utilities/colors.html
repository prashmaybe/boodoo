Opacity

Use .text-opacity-{10|25|50|75|100} for text alphras on a primary-tinged color.

CSS variables

Every color is exposed as a CSS custom property: --budu-primary, --budu-primary-rgb, --budu-gray-100, etc. Use them anywhere in your own CSS.
