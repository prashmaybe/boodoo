Wide Blocks Theme

The Wide Blocks Theme provides full block editor alignment for Gutenberg. Features edge-to-edge full width cover sections (alignfull), expanded wide block containers (alignwide), and custom theme.json design tokens mapped to Budu variables.

Theme Code Files

1. style.css

/*
Theme Name: Budu Wide Blocks Theme
Theme URI: https://boodoo.dihadiwala.com/docs/wordpress/wide-blocks.html
Author: Budu Framework Team
Author URI: https://boodoo.dihadiwala.com
Description: Full-width Gutenberg block editor WordPress theme with edge-to-edge cover banners built with Budu framework.
Version: 1.0.2
License: MIT
Text Domain: budu-wide-blocks
*/

@import url('https://boodoo.dihadiwala.com/dist/css/boodoo.min.css');

/* Block Editor Full & Wide Alignments */
.alignfull {
  width: 100vw;
  max-width: 100vw;
  margin-left: calc(50% - 50vw);
  margin-right: calc(50% - 50vw);
}

.alignwide {
  max-width: 1200px;
  margin-left: auto;
  margin-right: auto;
}

2. index.php

<?php
/**
 * Main Template File - Wide Blocks Theme
 */
get_header(); ?>

<main class="site-main py-0">
  <?php if ( have_posts() ) : while ( have_posts() ) : the_post(); ?>
    <article id="post-<?php the_ID(); ?>" <?php post_class(); ?>>
      <div class="entry-content">
        <?php the_content(); ?>
      </div>
    </article>
  <?php endwhile; endif; ?>
</main>

<?php get_footer(); ?>
