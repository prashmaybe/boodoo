The One Column Theme centers editorial content inside a narrow max-width container (container container-narrow mx-auto). Designed specifically for long-form publishing, essays, personal blogs, and documentation reading.

The Art of Minimalist Web Engineering

Published on August 24, 2026 • By Prashant • 5 min read

"Simplicity is prerequisite for reliability. When we strip away unnecessary JavaScript dependencies, our CSS layout becomes fast and robust."

Building readable web applications requires focusing on content first. The Budu One Column layout enforces an optimal line length (60–75 characters per line) to maximize reader comprehension and reduce visual fatigue across all screen sizes.

Theme Code Files

1. style.css

/*
Theme Name: Budu One Column Theme
Theme URI: https://boodoo.dihadiwala.com/docs/wordpress/one-column.html
Author: Budu Framework Team
Author URI: https://boodoo.dihadiwala.com
Description: Distraction-free single-column WordPress reading theme built with Budu framework.
Version: 1.0.2
License: MIT
Text Domain: budu-one-column

@import url('https://boodoo.dihadiwala.com/dist/css/boodoo.min.css');

.budu-one-col-container {
  max-width: 760px;
  margin-left: auto;
  margin-right: auto;
}

2. index.php

<?php
/**
 * Main Template File - One Column Theme
 */
get_header(); ?>

<main class="container py-5">
  <div class="budu-one-col-container">
    <?php if ( have_posts() ) : while ( have_posts() ) : the_post(); ?>
      <article id="post-<?php the_ID(); ?>" <?php post_class( 'bg-white p-4 p-md-5 rounded-4 shadow-sm mb-5 border border-light' ); ?>>
        <header class="text-center mb-4">
          <div class="mb-2"><?php the_category( ' ' ); ?></div>
          <h1 class="display-5 fw-bold text-dark mb-3">
            <a href="<?php the_permalink(); ?>" class="text-dark text-decoration-none"><?php the_title(); ?></a>
          </h1>
          <div class="text-muted small">
            Posted on <?php echo get_the_date(); ?> by <?php the_author(); ?>
          </div>
        </header>
        <?php if ( has_post_thumbnail() ) : ?>
          <div class="mb-4 rounded-3 overflow-hidden">
            <?php the_post_thumbnail( 'large', array( 'class' => 'img-fluid w-100' ) ); ?>
          </div>
        <?php endif; ?>
        <div class="entry-content text-secondary fs-5" style="line-height: 1.8;">
          <?php the_content( 'Continue reading →' ); ?>
        </div>
      </article>
    <?php endwhile; endif; ?>
  </div>
</main>

<?php get_footer(); ?>
