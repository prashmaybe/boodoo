Overview

Pickers enhance native browser inputs like <input type="color"> and <input type="date"> with uniform border styling, hex readout badges, integrated calendar icons, and dual date ranges.

Color Picker Wrapper

The .form-color-picker container couples a color swatch preview with an interactive hex readout badge:

<label class="form-color-picker" for="brandColor">
  <input type="color" class="form-control-color" id="brandColor" name="brandColor" value="#7c3aed">
  <span class="form-color-value"><span>#7c3aed</span></span>
</label>

Color Swatch Group

Predefined color choice palette using .swatch-group and .swatch-item:

<div class="swatch-group">
  <button type="button" class="swatch-item swatch-circle active" class="swatch-item swatch-circle active swatch-indigo" aria-label="Indigo"></button>
  <button type="button" class="swatch-item swatch-circle" class="swatch-item swatch-circle swatch-pink" aria-label="Pink"></button>
  <button type="button" class="swatch-item swatch-circle" class="swatch-item swatch-circle swatch-emerald" aria-label="Emerald"></button>
</div>
