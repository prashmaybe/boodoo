Password Meter

Real-time entropy evaluation, visual progress indicators, and dynamic checklist requirements for secure password inputs.

Interactive Strength Meter

Password strength: Empty

Usage

import { PasswordMeter } from 'boodoo';

const meter = new PasswordMeter('#demoPassword', {
  meterElement: '#demoPasswordMeter',
  minLength: 8,
  requireUppercase: true,
  requireNumbers: true,
  requireSpecial: true,
  onChange: (score, status) => {
    console.log(`Score: ${score}/100, Status: ${status}`);
  }
});

Options & Scoring Reference

Option / Callback Type Default Description
meterElement string | HTMLElement — Target container or progress bar reflecting entropy score updates.
minLength number 8 Minimum character length policy required for passing evaluation.
requireUppercase boolean true Requires at least one uppercase letter (A-Z) in password string.
requireSpecial boolean true Requires at least one special character punctuation symbol.
onChange (score: number, status: string) => void — Callback receiving computed score (0-100) and security level indicator.
