Password Meter

Real-time entropy evaluation, visual progress indicators, and dynamic checklist requirements for secure password inputs.

Interactive Strength Meter

Password strength: Empty

Usage

import { PasswordMeter } from 'boodoo';

const meter = new PasswordMeter('#demoPassword', {
  meterElement: '#demoPasswordMeter',
  minLength: 8,
  requireUppercase: true,
  requireNumbers: true,
  requireSpecial: true,
  onChange: (score, status) => {
    console.log(`Score: ${score}/100, Status: ${status}`);
  }
});
