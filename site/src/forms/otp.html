Overview

The OTP input automatically advances focus across digits, supports keyboard navigation, backspace jumps, and clipboard pasting.

Example

<div class="form-otp" data-boodoo="otp">
  <input type="text" class="form-otp-input">
  <input type="text" class="form-otp-input">
  <input type="text" class="form-otp-input">
  <input type="text" class="form-otp-input">
  <input type="text" class="form-otp-input">
  <input type="text" class="form-otp-input">
</div>
