What's included

Budu is downloadable in two forms: within which you'll find the following directories and files, logically grouping common resources and providing both compiled and minified variations.

The compiled CSS and JS are split into a few useful, deliberately small builds so you only ship what you need:

Precompiled

budu/
├── dist/
│   ├── css/
│   │   ├── budu.css            # full framework (components + grid + utilities + helpers)
│   │   ├── budu.min.css
│   │   ├── budu-grid.css       # grid + containers only
│   │   ├── budu-reboot.css     # normalize + base styles
│   │   ├── budu-utilities.css  # Tailwind-style utility classes
│   │   ├── budu-animations.css # motion utilities & keyframes
│   │   └── budu.less.css       # compiled from the Less build
│   └── js/
│       ├── budu.js             # UMD bundle (all components, ~56 KB)
│       └── budu.esm.js         # ES module, tree-shakeable

Source code

Build Budu from source using the Sass and Less files in the scss/ and less/ folders. The Sass source is modular — override variables, mixins, and maps to create your perfect output.
