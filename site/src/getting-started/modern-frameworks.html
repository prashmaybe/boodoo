Modern Framework Guides

Use Boodoo with modern web frameworks: Svelte 5, SolidJS, Astro, Remix/React Router 7, and Angular.

Astro Integration

Install Boodoo via npm or import CSS directly in your layout:

---
// src/layouts/Layout.astro
import 'boodoo/css';
---
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>Astro + Boodoo</title>
  </head>
  <body>
    <slot />
  </body>
</html>
Svelte 5 Integration
<script>
  import 'boodoo/css';
  let { count = 0 } = $props();
</script>

<div class="card p-3 shadow-sm">
  <h4 class="card-title text-primary"><span>Svelte 5 Component</span></h4>
  <button class="btn btn-primary" onclick={() => count++}>
    <span>Clicks: {count}</span>
  </button>
</div>
SolidJS & Remix / React Router 7
// In root layout or App entry
import 'boodoo/css';
import { useDisclosure } from 'boodoo/react'; // React / Remix / React Router 7
