Usage & CDN

Include Budu in your project using easy-to-use CDN links for quick prototyping, or reference the compiled bundles locally.

CSS only

The quickest way to get started is to drop the compiled and minified CSS into your page. Just one file gets you the global styles, grid, all components, and utilities.

<link href="https://budu.dihadiwala.com/dist/css/budu.min.css" rel="stylesheet">

You can also load just the grid, reboot, or utilities separately for the leanest possible page:

<!-- Grid only -->
<link href="https://budu.dihadiwala.com/dist/css/budu-grid.min.css" rel="stylesheet">

<!-- Utilities only -->
<link href="https://budu.dihadiwala.com/dist/css/budu-utilities.min.css" rel="stylesheet">

JavaScript

Many Budu components require the JavaScript bundle to function. Add it right before the closing </body> tag:

<script src="https://budu.dihadiwala.com/dist/js/budu.js"></script>

If you only need a subset, import individual components from the ESM build:

<script type="module">
  import { Modal, Toast, Dropdown } from 'https://budu.dihadiwala.com/dist/js/budu.esm.js';
  // components are auto-initialized from their data-* attributes
</script>

Local bundle

Prefer hosting yourself? Copy the contents of dist/ from the download into a folder and reference them relatively:

<link rel="stylesheet" href="css/budu.min.css">
<script src="js/budu.js"></script>

JavaScript modules

Our JavaScript is split into modules. The UMD-format bundle assigns a global Budu object with every component, so you can call them programmatically:

<script>
  Budu.toast('Hello from Budu!', { title: 'Welcome' });
  new Budu.Modal(document.getElementById('myModal')).show();
</script>
