Overview

Registration & Usage

When loading boodoo.js or calling registerCustomElements() in ES modules, all custom elements register automatically with the browser's customElements registry:

import { registerCustomElements } from 'boodoo/dist/js/boodoo.esm.js';

// Automatically defines <bd-theme-toggle>, <bd-otp>, <bd-rating>
registerCustomElements();
