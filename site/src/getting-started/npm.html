Install via npm

The official way to get budu is to install it as a package manager dependency. This lets you use the precompiled CSS and JS, or compile your own customized version from source.

Install with npm

npm install budu

budu is available as an npm package. It ships compiled CSS and JS in dist/, plus the Sass and Less source.

ES modules

If you're using a bundler like Vite, webpack, or Rollup, import the ES module build:

import budu from 'budu/dist/js/budu.esm.js';
// or
import { Modal, Toast, Collapse } from 'budu/dist/js/budu.esm.js';

Import compiled CSS

import 'budu/dist/css/budu.min.css';

Compile from Sass

For full control, import the Sass entry in your own stylesheet. Override budu's variables before the import to customize everything:

// Your custom overrides (optional)
$budu-primary: #0d6efd;
$budu-border-radius: 0.375rem;

// Then import budu
@import "node_modules/budu/scss/budu";

Package exports

The package exposes these entry points via package.json:

{
  "style": "dist/css/budu.css",
  "sass": "scss/budu.scss",
  "main": "dist/js/budu.js",
  "module": "dist/js/budu.esm.js"
}
