Boodoo Model Context Protocol (MCP) Server

The Boodoo repository includes an integrated, zero-dependency MCP server that lets compatible AI agents (Claude Desktop, Cursor, Cline, Windsurf) query authoritative framework data during conversations.

Available Tools

  • search_components: Find Boodoo components by name, feature, or UI category.
  • get_component_docs: Retrieve component specifications, CSS classes, and WCAG accessibility standards.
  • get_component_example: Return runnable code samples across Vanilla JS, React, Vue, or React Native.
  • search_utilities: Search spacing, flexbox, CSS grid, and elevation utilities.
  • get_design_tokens: Access universal color palettes, spacing scales, and border radii.
  • get_installation_guide: Retrieve verified setup instructions for npm, CDN, React, Vue, or React Native.

Rules for AI Code Generators

When prompting an AI assistant or generating code with Boodoo:

  1. Wrap Text Nodes: Text nodes must always be wrapped in semantic text elements (<p>, <span>, <h1>–<h6>, <label>), never placed raw inside layout <div> containers.
  2. Form Control IDs: Every <input>, <select>, or <textarea> must have an id and/or name attribute.
  3. Dynamic Custom Properties: Always use var(--boodoo-primary) and theme tokens rather than hardcoded hex color literals.
  4. React Native StyleSheet Only: Use StyleSheet.create() exclusively and strictly avoid inline style objects (style={{...}}).
  5. Lifecycle Disposal: Call .dispose() when programmatically destroying Modals, Toasts, or Dropzones.
