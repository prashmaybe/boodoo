Native components

Style hybrid, desktop, or cross-platform web applications (such as Electron, Tauri, React Native Web, or Cordova/Capacitor) using platform-native visual conventions for Windows, macOS, iOS, iPadOS, Android, and Linux. For Electron configuration and titlebar drag mechanics, read the Electron Desktop guide.
