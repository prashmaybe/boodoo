Native components

Style hybrid, desktop, or cross-platform web applications (such as Electron, Tauri, React Native Web, or Cordova/Capacitor) using authentic platform-native visual conventions for Windows 11, macOS Sonoma, iOS 17/18, iPadOS, Android Material Design 3, Linux GNOME Adwaita, and classic Photon Desktop. For Electron configuration and titlebar drag mechanics, read the Electron Desktop guide.
