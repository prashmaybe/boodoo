Collapse

Toggle the visibility of content across your project with a few classes and our JavaScript plugin.

How it works

The collapse plugin uses a few classes to handle the heavy lifting:

  • .collapse hides content.
  • .collapsing is applied during transitions.
  • .collapse.show shows content.
  • data-budu-toggle="collapse" on the trigger, with data-budu-target (or an href) pointing to the collapsible element.

Multiple toggles & targets

A single trigger can control multiple targets by passing a space-separated selector to data-budu-target, or multiple triggers can control the same target.

<!-- single button, two targets -->
<button data-budu-toggle="collapse"
        data-budu-target="#targetOne #targetTwo">Toggle both</button>
