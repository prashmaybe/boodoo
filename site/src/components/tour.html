Tour

Step-by-step product walkthroughs, contextual feature callouts, backdrop highlights, and keyboard-driven onboarding tours.

Product Tour Demo

Tour Configuration

import { Tour } from 'boodoo';

const tour = new Tour({
  steps: [
    {
      target: '#nav-home',
      title: 'Navigation Header',
      content: 'Access all documentation and starters here.',
      placement: 'bottom'
    },
    {
      target: '#searchDocs',
      title: 'Global Search',
      content: 'Instantly find any utility, class, or component.',
      placement: 'bottom'
    }
  ]
});

document.getElementById('startTourBtn').addEventListener('click', () => {
  tour.start();
});

Options & Events Reference

Option / Event Type Default Description
steps Array<TourStep> [] Array of tour step descriptors containing target, title, content, and placement.
backdrop boolean true Whether to dim the page background and spotlight the active target element.
start() () => void — Launches the walkthrough sequence starting at step 0.
next() / prev() () => void — Advances or steps back through tour checkpoints with keyboard navigation.
boodoo:tour:step CustomEvent — Dispatched on window whenever the active walkthrough step changes.
