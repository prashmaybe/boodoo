Block buttons

Use .d-grid and a gap utility to create full-width, stacked buttons. The .btn-block class also works for a single full-width button.

Material ripple

Add the .ripple class (or the data-boodoo-ripple attribute) to any element to get a Material ink-ripple on click — no JS config needed.
