Overview

Boodoo Charts deliver zero-dependency, ultra-lightweight data visualizations inspired by Chart.js. Render bar charts, continuous line charts, and donut analytics that seamlessly bind to Boodoo theme tokens and dark mode.

Interactive Bar Chart

Bar charts display categorized numeric metrics with automated scaling, gridlines, and interactive hover tooltips.

Monthly Framework Downloads
2026 Metrics 
<div id="myBarChart" class="chart-wrapper">
  <canvas id="myBarCanvas" aria-label="Downloads Bar Chart"></canvas>
</div>

<script>
  const chart = new boodoo.Chart('#myBarChart', {
    type: 'bar',
    data: {
      labels: ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'],
      datasets: [{
        label: 'Downloads',
        data: [12400, 19800, 24500, 31200, 42100, 58400]
      }]
    }
  });
</script>

Continuous Line Chart

Continuous line charts visualize trends over chronological sequences with smoothed paths and responsive touch indicators.

API Response Latency (ms)
99.9% Uptime 
const lineChart = new boodoo.Chart('#demoLineChart', {
  type: 'line',
  data: {
    labels: ['00:00', '04:00', '08:00', '12:00', '16:00', '20:00'],
    datasets: [{
      label: 'Latency (ms)',
      data: [42, 38, 55, 62, 49, 36],
      borderColor: 'var(--boodoo-info, #0ea5e9)'
    }]
  }
});

Donut & Pie Charts

Donut charts offer proportional slice visualization with percentage calculations, hover tooltips, and centered counters.

Traffic by Platform
const donutChart = new boodoo.Chart('#demoDonutChart', {
  type: 'donut',
  data: {
    labels: ['Desktop', 'Mobile', 'Tablet'],
    datasets: [{
      data: [58, 34, 8]
    }]
  }
});
