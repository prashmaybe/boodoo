Overview

Boodoo Charts deliver zero-dependency, ultra-lightweight data visualizations inspired by Chart.js. Render bar charts, continuous line and area charts, full-size pie and donut analytics, polar area slices, and multi-axis radar charts that seamlessly bind to Boodoo theme tokens and dark mode.

Interactive Bar Chart

Bar charts display categorized numeric metrics with automated scaling, gridlines, and interactive hover tooltips.

Monthly Framework Downloads
2026 Metrics 
const chart = new boodoo.Chart('#myBarChart', {
  type: 'bar',
  data: {
    labels: ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'],
    datasets: [{
      label: 'Downloads',
      data: [12400, 19800, 24500, 31200, 42100, 58400]
    }]
  }
});
