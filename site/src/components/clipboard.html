Clipboard

Lightweight asynchronous clipboard copy utility with automatic focus restoration, accessible screen reader live feedback, and tooltip state updates.

Interactive Demo

Copied to clipboard successfully!

JavaScript Usage

import { clipboard } from 'boodoo';

// Direct string copy
await clipboard.writeText('npm install boodoo');

// Or bind directly to button triggers
clipboard.bind('#copyBtn', {
  target: '#clipSource',
  successText: 'Copied!',
  timeout: 2000
});
