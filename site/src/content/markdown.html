Markdown & Rich Text

Lightweight, XSS-sanitized Markdown parser and rich text renderer adhering to semantic text wrapping and secure link allowlists.

Live Markdown Preview

Usage

import { Markdown } from 'boodoo';

// Static string rendering with XSS sanitation
const safeHtml = Markdown.render('# Hello Boodoo\n\n- Zero dependencies\n- Mobile-first CSS');

// Or bind directly to a container
const md = new Markdown('#demoMarkdown', {
  content: '### Real-Time Markdown\n\nRender **bold**, *italic*, [safe links](https://boodooframework.com), and `code` with zero runtime dependencies.'
});
