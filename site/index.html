Cross-Platform Ready

Now in React Native & Mobile

Bring Boodoo's clean modern aesthetics to iOS and Android. Zero DOM, pure React Native StyleSheet engine, drop-in React Native Paper theme presets, and universal design tokens.

Native Mobile Components (`boodoo/react-native`)

Drop-in `Button`, `Card`, `Badge`, `Text`, and `TextInput` with auto light/dark theming and touch ripples. 0 external packages, Expo Go ready.

React Native Paper Theme Adapter (`boodoo/paper`)

Skin your existing React Native Paper app in 2 lines with Boodoo's MD3 Light & Dark theme presets. Zero rewrite needed.

Universal Design Tokens (`boodoo/tokens`)

Shared brand palettes, spacing units, border radii, typography, and elevation shadows in JS and JSON formats.

Mobile Screen (Expo / React Native) 
// Zero-bloat mobile component with Boodoo
import { BoodooProvider, Card, Button, Badge } from 'boodoo/react-native';

export default function App() {
  return (
    <BoodooProvider theme="auto">
      <Card variant="elevated">
        <Card.Title title="Boodoo Mobile" />
        <Card.Content>
          <Badge variant="success">iOS & Android</Badge>
        </Card.Content>
        <Card.Actions>
          <Button variant="primary" size="sm">
            Get Started
          </Button>
        </Card.Actions>
      </Card>
    </BoodooProvider>
  );
}
