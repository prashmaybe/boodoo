# boodoo React + Vite Starter

Quickly build React applications styled with the boodoo CSS & JS framework.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Included Features

- boodoo full CSS + JS integration in React
- Vite development environment with instant Hot Module Replacement (HMR)
- Ready-to-customize interactive counter and card components
