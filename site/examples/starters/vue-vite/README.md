# boodoo Vue 3 + Vite Starter

Quickly build Vue 3 applications styled with the boodoo CSS & JS framework.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Included Features

- boodoo full CSS + JS integration in Vue 3
- Single File Components (.vue) support
- Vite development environment with instant HMR
