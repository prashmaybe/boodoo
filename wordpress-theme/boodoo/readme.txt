A performance-first WordPress Block Theme built on the Boodoo CSS design framework.

== Description ==

Boodoo is a modular, mobile-first WordPress Block Theme and Design System Platform designed to power modern blogs, WooCommerce stores, corporate sites, portfolios, and magazines.

== Features ==
* Full Site Editing (FSE) & theme.json token support
* Responsive Flexbox and Grid layouts
* Custom Block Patterns for Heroes, Features, Pricing, and FAQs
* WooCommerce integration
* Accessibility ready (WCAG 2.2 AA compliant)
* Optimized for Google PageSpeed 90+
* Dark Mode and multiple color style variations

== Installation ==
1. Upload the `boodoo` directory to `/wp-content/themes/`.
2. Activate the theme through 'Appearance > Themes' in WordPress.
3. Access the Site Editor via 'Appearance > Editor' to customize layout styles and patterns.
